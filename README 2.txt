BLC ESPORTS — WEBSITE STARTER
================================

This is a fresh, mobile-first static website starter for BLC ESPORTS.

FILES
- index.html: website content and page sections
- styles.css: visual design and responsive layout
- script.js: mobile navigation
- assets/blc-logo.jpeg: supplied BLC logo

HOW TO USE
1. Upload the contents of this folder to a GitHub repository.
2. Connect that repository to Cloudflare Pages.
3. Set the build command to blank / none.
4. Set the build output directory to / (root).
5. Deploy.

IMPORTANT BEFORE PUBLIC LAUNCH
- Replace the recruitment button URLs with the real player and staff application links.
- Add confirmed player names, profile images and achievements.
- Add official social links and contact email.
- Add a privacy notice and suitable form handling before collecting personal information.
- The current site is a visual starter; no secure management dashboard or application database is included yet.
- The Discord invite link in this starter is the BLC invite previously supplied in chat. Check it is still valid before publishing.

No existing website is changed by this package.
